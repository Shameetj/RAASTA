# Frontend Components (Developer 3)

## Responsibilities
Reusable React UI components:
- `Navbar`: Header with app branding and profile toggle
- `ProfileSwitcher`: Toggle between Wheelchair Mode and Deaf / Hard of Hearing Mode
- `VisualAlertBanner`: High-contrast, flashing warning banner with tactile vibration indicator
- `AccessibilityScoreCard`: Visual 0–100 score gauge with ADA compliance breakdown
- `TurnByTurnCards`: Step-by-step visual navigation cards with hazard badges
- `ReportBlockageModal`: Popup modal for reporting barriers
