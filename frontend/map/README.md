# Frontend Map Module (Developer 3)

## Responsibilities
- Leaflet map initialization and container sizing
- Tile layer integration (OpenStreetMap / CartoDB)
- Multi-colored route polylines:
  - Blue: Standard direct path
  - Red dashed: Segment blocked by physical obstacles
  - Green: Recommended accessible step-free detour
- Custom map marker pins:
  - Origin / Start marker
  - Destination marker
  - Obstacle markers (Stairs, Blocked Ramp, Construction) with informative detail popups
  - Ramp markers (Wheelchair accessible ramp icons)
- Floating map legend and "Report Blockage" button
